Details

Is KMReader an official Komga app?

No. KMReader is an independent open-source client built for Komga users.

Which readers are available?

DIVINA on iOS, macOS, and tvOS. EPUB and PDF on iOS and macOS.

Can I use multiple Komga servers?

Yes. Save and switch between servers, sign in with password or API key, and manage keys in the app.

How does offline mode work?

Downloaded books stay readable offline, and reading progress syncs when you reconnect.

Which server should I run?

Any Komga 1.19.0+ server works, including kmrs, the single-binary Rust server from the same family.

Can admins manage library data in-app?

Yes. Metadata editing, library and media management, task monitoring, and log review are built in.
